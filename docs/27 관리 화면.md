# 27 관리 화면

> 라이선스를 **화면에서** 발급하고 좌석을 해제한다. SQL 편집기로 하던 일이다.
> 서버는 [[24 라이선스 서버 배포]], 설계 전제는 [[20 라이선스와 복제 방지]].

주소: `https://anfilt-homepage.netlify.app/admin/license/` (검색 비노출)

## 왜 테이블에 직접 붙지 않는가

`ra_licenses` 는 RLS 를 켜고 **정책을 하나도 두지 않았다.** 그것이 곧
"anon 키로는 아무도 라이선스 목록을 훑을 수 없다" 였다.

관리 화면을 만들자고 관리자 UID 정책을 추가하면, 목록으로 가는 **두 번째
경로**가 생긴다. 문을 늘리는 대신 있던 문(Edge Function)에 창구를 하나 더 냈다.

`POST /functions/v1/license/admin` · 자격은 `RA_ADMIN_TOKEN` 하나.

| op | 하는 일 |
|---|---|
| `list` | 라이선스 + 활성화 기기 (요청 한 번에 화면이 완성된다) |
| `issue` | 새 키 발급 — 서버가 뽑는다 |
| `update` | 좌석·상태·만료·메모 (칸은 화이트리스트) |
| `release` | 좌석 해제 (기기 하나) |
| `delete` | **한 번도 쓰지 않은** 키만 삭제 |

## 세 자격을 헷갈리지 말 것

| 이름 | 누가 쓰나 | 새면 |
|---|---|---|
| 라이선스 키 `ANF-…` | 고객 PC | 그 계약 하나 (좌석 수로 막힌다) |
| `RA_TRIAL_TOKEN` | 체험판 서버 | 팩이 샌다 (→ [[26 팩을 저장소 밖으로]]) |
| `RA_ADMIN_TOKEN` | 관리 화면 | **남이 라이선스를 찍어낸다** |

셋 중 관리 토큰이 가장 무겁다. **절대 같은 값을 쓰지 말 것.**

브라우저에서는 `sessionStorage` 에만 둔다 — 탭을 닫으면 사라진다. '잠그기'는
숨기기가 아니라 **목록을 지우고** 잠근다(자리를 비운 사이 개발자 도구로 읽히지
않게). 무차별 대입은 [[24 라이선스 서버 배포]]의 응답 시간 바닥(2초)이 함께 막는다.
그래서 버튼마다 눌린 표시("처리 중…")가 있다 — 느린 것이 정상이다.

## 정지 · 해지 · 좌석 해제는 즉시가 아니다

고객 PC 는 팩을 **최대 30일** 캐시한다(오프라인으로 쓰라고 만든 장치다).
그래서 무엇을 눌러도 **그 PC 가 갱신하러 올 때** 효력이 생긴다.

| 하고 싶은 일 | 누를 것 |
|---|---|
| PC 를 바꿨다 / 퇴사자 자리를 비운다 | **좌석 해제** — 그 자리에 새 PC 가 들어간다 |
| 대금 미납 · 분쟁 — 갱신을 막는다 | **정지** (되돌릴 수 있다) |
| 계약 종료 | **해지** (기록은 남는다) |
| 이메일을 잘못 적고 발급했다 | **삭제** — 활성화 이력이 없을 때만 보인다 |

즉시 끊는 방법은 없다. 그건 라이선스가 아니라 오프라인 동작을 포기해야
가능한 일이고, 그 값은 [[18 설치형 패키지]]가 파는 것과 정면으로 어긋난다.

## 배포

함수는 [[24 라이선스 서버 배포]]와 같다. 관리 토큰만 새로 심으면 된다.

```powershell
$env:SUPABASE_ACCESS_TOKEN = Read-Host "액세스 토큰"
# RA_ADMIN_TOKEN 은 32바이트 난수로 만든다 (체험판 토큰과 다른 값!)
python packaging\make_trial_token.py        # 같은 생성기를 쓴다
& "$env:LOCALAPPDATA\supabase-cli\supabase.exe" secrets set --project-ref unjhdoulorbmpepnkcpr --env-file <파일>
& "$env:LOCALAPPDATA\supabase-cli\supabase.exe" functions deploy license --no-verify-jwt --project-ref unjhdoulorbmpepnkcpr --workdir "<저장소>"
```

토큰을 **명령줄에 직접 쓰지 않는다** — PowerShell 기록에 남는다. `--env-file` 로 준다.

홈페이지 쪽은 `admin-license.html` 하나이고 `netlify.toml` 이 `/admin/license/`
로 복사한다. 다른 페이지와 달리 이 파일은 **빠지면 빌드를 실패시킨다** —
관리 화면이 조용히 사라지면 발급을 못 한다.

### 다른 도메인을 붙일 때

브라우저에서 오는 유일한 통로라 CORS 를 탄다. 허용 주소는 함수에 박혀 있고,
`RA_ADMIN_ORIGINS`(쉼표 구분) 로 덧붙일 수 있다 — 도메인을 옮긴다고 코드를
고치지 않아도 되게. 여기에 없는 주소에서 부르면 브라우저가 막는다.

## 시험

화면은 가짜 서버로 확인했다(브라우저에서 발급·수정·해제·삭제 전부).
서버 쪽은 실서버에 대고 본다 — **스스로 뒤처리한다.**

```powershell
$env:RA_ADMIN_TOKEN = Read-Host "관리 토큰"
python tests\test_admin_live.py
```

시험용 키를 하나 발급해 실제로 활성화까지 시켜 보고, "쓰는 중이라 못 지운다"
까지 확인한 뒤 해제·삭제하고 끝낸다. 판매용 목록에 시험 찌꺼기가 쌓이면
다음 사람이 그걸 지우기 무서워한다 — 지워도 되는 것인지 알 수 없으니까.
