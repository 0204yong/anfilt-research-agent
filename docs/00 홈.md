# 멀티 LLM 리서치 에이전트 — 설계서

여러 LLM(Claude·GPT·Gemini)이 동일한 주제를 병렬 조사하고 상호 토론한 뒤,
종합된 결과를 PPT / Word / Excel 보고서로 생성하는 Streamlit 프로그램의 설계 문서.

> 프로젝트 경로: `C:\ANFILT_AI\Research Agent`
> 실행: `streamlit run app.py`

## 문서 목차

- [[03 LLM 프로바이더]] — 3사 연동 상세, 모델, 알려진 이슈와 해결책
- [[04 레퍼런스 시스템]] — URL 수집 / 자동 탐색 / 파일 첨부
- [[05 보고서 생성]] — 분량 계획, PPT 3종 레이아웃, Word/Excel 빌더
- [[06 PPT 디자인 엔진]] — Gamma·Canva·Google Slides 연동과 키 발급 절차
- [[07 설치와 실행]] — 환경 구성, 환경변수, 실행 방법
- [[08 작업 이력]] — 날짜별 개발 내역과 의사결정 기록
- [[09 향후 고도화 백로그]] — 다음 단계 아이디어와 미해결 항목

- [[11 원커맨드 배포]] — "배포해줘" 한 마디로 전체 자동 배포 (git push = 배포)

- [[14 라이트 모드]] — 지식창고 우선 저비용 모드 (경량 모델 1~2회 호출, 업무 템플릿)
- [[15 자동 모니터링과 알림]] — 사이트·키워드 정기 감시 → 새 내용만 요약·축적 → 이메일/카톡
- [[16 지식 비서]] — 볼트에 있는 것만으로 답하는 개인 사서 (근거 인용·없으면 없다고 답함)
- [[17 다중 사용자와 테넌트 분리]] — (보류) 호스팅형 SaaS화: 볼트 분리·RLS 격리·비용 방어
- [[18 설치형 패키지]] — 정식판: 사용자 PC 설치, 본인 API 키·본인 옵시디언 폴더
- [[19 두 제품 구성과 자동 업데이트]] — **판매 구조**: 체험판(호스팅) + 정식판(설치), 홈페이지 다운로드·자동 패치
- [[20 라이선스와 복제 방지]] — 구매자만 실행 가능하게: 프롬프트 팩 인출 권한 + 기기 바인딩
- [[21 휴대폰에서 쓰기]] — 폰에서 볼트 열람·비서 질의: 클라우드 볼트만으로는 부족한 이유
- [[22 설치판 아키텍처]] — **구현 문서**: 런타임·디스크 레이아웃·LocalStore·팩·상태 처리
- [[23 설치판 구현 계획]] — **구현 문서**: 0~8단계 순서와 완료 기준(DoD)·회귀 방어
