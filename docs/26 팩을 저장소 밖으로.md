# 26 팩을 저장소 밖으로

> 설계 전제는 [[20 라이선스와 복제 방지]], 서버는 [[24 라이선스 서버 배포]].
> **이 문서는 "왜 팩이 저장소에 없는가"** 다.

## 무엇이 문제였나

앱 저장소 `anfilt-research-agent` 는 **공개**다. 체험판을 Streamlit Community
Cloud 로 배포하려면 그래야 한다 — 비공개로 바꿔 봤더니 이미 배포된 앱이 소스를
읽지 못해 그 자리에서 죽었다 (2026-08-14, [[08 작업 이력]] 43).

그런데 [[20 라이선스와 복제 방지]]는 **이 제품의 값어치가 코드가 아니라
프롬프트와 시드**라고 못 박고 있다. 그것이 공개 저장소에 있으면 라이선스 서버는
지킬 것이 없다 — 복제본은 "조사를 시작할 부품이 없어야" 하는데, 부품을 GitHub
에서 그냥 받을 수 있었다.

`build.ps1` 이 설치판에서 팩과 시드를 **일부러 빼는** 것도 같은 이유였다.
빼 놓고 저장소에 두면 아무 의미가 없다.

## 어떻게 바꿨나

| 있는 곳 | 무엇 |
|---|---|
| `0204yong/anfilt-pack` (**비공개**) | 원본 — `prompts/pack.json` · `vault_seed/` |
| Supabase Storage `license-packs/pack.json` | 배포본 — 둘을 합쳐 구운 것 |
| `anfilt-research-agent` (공개) | **없음** |

앱은 팩을 **인출**한다. 자격이 둘로 갈린다.

- **정식판**: 라이선스 키 → 서명된 팩 (→ `core/licensing.py`)
- **체험판**: 공유 토큰 `RA_TRIAL_TOKEN` → 팩 (→ `core/packfetch.py`)

체험판 토큰은 Streamlit Secrets 와 Supabase 시크릿 **두 곳에만** 있다.
서명을 붙이지 않는 이유: 받는 쪽이 우리 서버이고 TLS 로 온다. 서명은 *고객
PC 에 있는 팩*이 진짜인지 가리려는 장치라 여기서는 지킬 것이 다르다.

`core/packs.py` 의 호출부 넷(`get`·`render`·`schema`·`conf`)은 **바뀌지 않았다.**
`_load()` 의 순서에 한 겹이 붙었을 뿐이다.

    1. 정식판 라이선스 팩 → 2. 체험판 인출 팩 → 3. 개발용 원본 폴더 → 4. PackError

3번은 개발 편의다. `anfilt-pack` 을 받아 뒀으면 토큰 없이도 로컬에서 돌아간다.
**정식판에서는 3번을 쓰지 않는다** — 개발 PC 에는 그 저장소가 있으므로, 그대로
두면 라이선스 없이도 팩이 잡혀 활성화 검사를 우회한다.

## 체험판이 서버에 매이지 않게

새 단일 장애점을 만들면 안 된다. 그래서 `packfetch.load()` 는

    메모리 → 신선한 캐시(6시간) → 서버 → **낡은 캐시**

마지막이 핵심이다. 서버가 흔들려도 체험판은 낡은 팩으로 계속 돈다 — 프롬프트가
며칠 낡는 것이 화면이 멈추는 것보다 훨씬 낫다.

반대로 **캐시도 서버도 없으면 조용히 넘어가지 않고 터뜨린다.** 그러지 않으면
토큰을 잘못 넣은 체험판이 "그냥 되는 것처럼" 보이다가, 다음 배포에서 죽는다.

## ⚠️ 이미 나간 것은 돌아오지 않는다

2026-08-14 이전의 시드 35노트와 프롬프트는 **공개 저장소 이력에 남아 있다.**
지금 지워도 옛 커밋을 체크아웃하면 나온다. 이력을 다시 쓰는 방법이 있지만
이미 복제된 것은 회수되지 않는다.

그래서 이 작업의 뜻은 "회수"가 아니라 **"앞으로의 값어치를 서버 뒤에 두는 것"**
이다. 실질적 효과를 보려면 **팩을 한 번 갈아야** 한다 — [[20 라이선스와 복제 방지]]
의 L3(팩 회전)이 정확히 이 상황을 위한 대비책이다: "어렵게 한 번 빼내도 다음
패치면 낡는다."

## 프롬프트를 고칠 때

```powershell
git clone https://github.com/0204yong/anfilt-pack.git      # 처음 한 번
```

`anfilt-pack` 에서 고친 뒤, 앱 저장소에서:

```powershell
python packaging\make_pack.py --out pack.json
```

Supabase → Storage → `license-packs` → `pack.json` 덮어쓰기 → 로컬 파일 삭제.
**앱 재배포가 필요 없다.** 체험판은 6시간 안에, 정식판은 갱신 주기에 따라 받는다.

> `make_pack.py` 는 `RA_PACK_DIR` → `../anfilt-pack` → `C:\ANFILT_AI\anfilt-pack`
> 순으로 원본을 찾는다.

## 시험

`tests/packfix.py` 의 `install_pack()` 이 원본을 캐시에 끼운다. 네트워크를
타지 않으려는 것이다. 팩이 필요한 묶음은 이걸 부른다 — 부르지 않으면
"라이선스 없는 정식판"을 시험하는 셈이 되어, 보려던 것 대신 팩 부재만 확인한다.

실서버 인출은 따로 본다 (토큰이 필요하다):

```powershell
$env:RA_TRIAL_TOKEN = Read-Host "체험판 토큰"
python tests\test_pack_live.py
```
