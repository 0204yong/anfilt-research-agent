# 21 휴대폰에서 쓰기

> 상태: **설계 확정 (2026-08-07) · 미착수**.
> [[18 설치형 패키지]](정식판이 사용자 PC에서 돈다)의 후속 질문에 답하는 문서.

## 질문 (사용자, 2026-08-07)

> "사용자가 휴대폰에서도 비서 기능을 쓸 수 있어야 한다. 그러려면 지식볼트만
> 자신의 클라우드(구글·원드라이브)에 두면 되나?"

## 답: 그것만으로는 안 된다 — 절반만 해결된다

클라우드에 볼트를 두면 **파일이 폰에 도착**한다. 그런데 비서는 파일이 아니라
**프로그램**이다. [`librarian.ask()`](core/librarian.py:236) 는 볼트 전체를 스캔해
관련 노트를 고르고, 그걸 컨텍스트로 **LLM을 호출**한다. 폰에는 그 코드도, 사용자
API 키도, 프롬프트 팩(→ [[20 라이선스와 복제 방지]])도 없다.

> **클라우드 저장소는 파일 동기화를 주지, 연산을 주지 않는다.**

그래서 둘로 나눠서 답한다.

| 원하는 것 | 클라우드 볼트만으로 | 필요한 것 |
|---|---|---|
| 폰에서 노트 **읽기·검색** | ✅ 된다 (조건부 — 1절) | Obsidian 모바일 + 동기화 수단 |
| 폰에서 **모니터링 알림** 받기 | ✅ **이미 된다** | 없음 — 이메일·카톡으로 온다 (→ [[15 자동 모니터링과 알림]]) |
| 폰에서 **비서에게 질문** | ❌ 안 된다 | 어딘가에서 프로그램이 돌아야 한다 (2절) |
| 폰에서 **조사 실행** | ❌ 안 된다 | 위와 같음 (20분 걸리는 작업이라 폰에 안 맞기도 하다) |

---

## 1. 볼트를 폰에서 보기 — 되지만 "구글 드라이브에 넣으면 끝"은 아니다

Obsidian 모바일은 볼트를 **로컬 폴더**로 연다. 클라우드 폴더를 직접 여는 것은
플랫폼마다 사정이 다르다.

- **iOS**: iCloud Drive는 공식 지원. 구글 드라이브·OneDrive는 파일이 "온디맨드"로
  내려오는 방식이라 **볼트로 쓰기에 신뢰하기 어렵다.**
- **Android**: 로컬 폴더면 되므로, 폴더를 미러링해 주는 동기화 앱을 끼우면 동작한다.
  (드라이브·OneDrive 공식 앱은 기본적으로 폴더를 로컬 미러링하지 않는다.)

**확실한 두 방법**은 따로 있다.

| 방법 | 성격 | 비고 |
|---|---|---|
| **Obsidian Sync** (공식·유료) | 종단간 암호화, 양 플랫폼 모두 안정 | 월 구독. 가장 손이 안 간다 |
| **Remotely Save** (커뮤니티 플러그인) | S3·Dropbox·OneDrive·WebDAV 연결 | 무료. 설정 한 번 필요 |

> ⚠️ 위 플랫폼 동작은 앱 업데이트로 바뀐다. **고객에게 안내하기 전에 실기기로
> 한 번 확인**하고, 확인한 날짜와 함께 매뉴얼에 적는다. "된다고 들었다"로 안내하면
> 지원 문의가 그대로 돌아온다.

### 동기화와 앱 쓰기가 겹칠 때

PC의 앱이 볼트에 노트를 쓰는 동안 클라우드 동기화가 돌면 충돌 사본이 생길 수 있다.
[[18 설치형 패키지]] 3절의 **원자적 쓰기(임시 파일 → `os.replace`)** 와 **mtime 확인**이
여기서 값을 한다. 그래도 동기화 도구가 만든 `conflicted copy` 파일은 생길 수 있으니,
앱 시작 시 볼트에서 그런 파일을 발견하면 **화면에 알린다**(자동 병합은 하지 않는다 —
사용자 판단 영역).

## 2. 폰에서 비서를 쓰려면 — PC를 개인 서버로

**정식판은 이미 웹앱이다.** Streamlit이 HTTP로 서비스하므로, 폰 브라우저가 PC에
닿기만 하면 비서 화면이 **그대로** 뜬다. 새로 만들 앱이 없다는 뜻이다.

```
[폰 브라우저] ──▶ [집·사무실 PC의 정식판] ──▶ 볼트(로컬 폴더) + 사용자 LLM 키
                        ▲
                   프롬프트 팩·라이선스도 여기 있음 → 폰은 추가 활성화 불필요
```

### 세 가지 접속 방식

| 방식 | 난이도 | 보안 | 권장 |
|---|---|---|---|
| **같은 Wi-Fi** (집·사무실 안) | 가장 쉬움 | 내부망 한정 | **기본값** |
| **Tailscale** (개인 VPN) | 앱 설치 + 로그인 | 공개 노출 없음 | **외부 접속 권장** |
| Cloudflare Tunnel | 중간 | 공개 URL + 접근 제어 필요 | 대안 |
| 공유기 포트 포워딩 | — | **위험** | **금지** |

Tailscale을 권하는 이유: 공인 IP·포트 개방·인증서가 전부 필요 없고, 폰과 PC가
같은 사설망에 있는 것처럼 동작한다. 무료 개인 플랜으로 충분하다.

### 앱에 넣을 것 — "휴대폰 접속" 토글

설정 화면에 스위치 하나를 둔다. 켜면:

1. Streamlit을 `server.address=0.0.0.0` 으로 재기동 (지금은 localhost 전용)
2. 접속 주소를 **QR 코드로 표시** — 폰으로 찍으면 바로 열린다
3. **접속 PIN을 강제 발급** (아래)
4. 끄면 즉시 localhost 전용으로 되돌린다

### PIN 게이트가 다시 필요해진다

[[18 설치형 패키지]] 9절에서 "비밀번호 게이트 제거(localhost라 불필요)"라고 했는데,
**휴대폰 접속을 켜는 순간 그 전제가 깨진다.** 삭제하지 말고 **조건부로 되살린다** —
[ui_common.py:39](ui_common.py:39) 의 `require_password` 를 PIN 게이트로 재사용한다.
(체험판 볼트 이주에서 zip 코드가 되살아난 것과 같은 패턴이다.)

- 휴대폰 접속이 **켜져 있을 때만** 게이트 활성화, PIN 미설정이면 **켜지지 않는다**(fail-closed)
- 같은 Wi-Fi여도 요구한다 — 카페·공유 오피스 Wi-Fi를 생각하면 당연하다

### 라이선스와 좌석

**폰 접속은 새 기기 활성화가 아니다.** 폰은 브라우저일 뿐이고 프로그램은 PC에서
돈다. 좌석을 소모하지 않는다(→ [[20 라이선스와 복제 방지]]). 이건 판매 문구에
명시할 만한 장점이다 — "1 라이선스로 PC 1대 + 내 폰".

### 모바일 화면

[지식 비서 페이지](pages/2_📚_지식_비서.py)는 질문–답변 구조라 폰에 잘 맞는다.
좁은 화면에서 `layout="wide"` 와 사이드바가 걸리적거리므로, **비서 페이지에만**
모바일 레이아웃(사이드바 접기, 근거 노트는 접힌 상태 기본)을 적용한다.
조사 실행 화면까지 모바일 최적화할 필요는 없다 — 20분짜리 작업을 폰에서
시작하는 동선은 현실적이지 않다.

## 3. "PC가 꺼져 있어도 되게" 하려면

그건 결국 **호스팅**이고, [[18 설치형 패키지]]의 핵심 판매 논리("고객사 자료가
저희 서버를 거치지 않습니다")와 정면으로 부딪힌다. 그래서 기본 제공하지 않는다.

수요가 확인되면 **옵트인 유료 옵션**으로만 연다.

- 볼트의 **암호화 사본**만 서버에 두고, 비서 질의만 처리 (조사·첨부 파일 제외)
- 고객이 명시적으로 켜야 하고, 화면에 "이 기능은 볼트 사본을 서버에 둡니다"를 상시 표시
- 계약서에 위탁 처리 조항 별도
- 기술 기반은 [[17 다중 사용자와 테넌트 분리]]의 테넌트 설계를 그대로 꺼내 쓴다
  — **보류해 둔 문서가 여기서 다시 쓰일 자리**다

[[19 두 제품 구성과 자동 업데이트]] 6절 로드맵에 끼우면:

| 단계 | 내용 | 비고 |
|---|---|---|
| 5단계와 함께 | 휴대폰 접속 토글 + PIN 게이트 + QR + 비서 페이지 모바일 레이아웃 | **작다** — 게이트 코드 재사용, 신규 화면 없음 |
| 매뉴얼 | 볼트 모바일 동기화 안내(Obsidian Sync / Remotely Save) + Tailscale 안내 | 실기기 확인 후 작성 |
| 후순위 | 클라우드 비서 모드 (3절) | 수요 확인 후 |

## 5. 정리 — 사용자에게 안내할 문장

> **볼트를 클라우드에 두면 폰에서 노트를 보고 검색할 수 있습니다.**
> **비서에게 질문하려면 PC의 프로그램이 켜져 있어야 하고, 폰은 브라우저로 접속합니다**
> (같은 Wi-Fi 또는 Tailscale). **모니터링 알림은 지금도 폰으로 옵니다.**
